<li><b><a href="http://anthonyrios.net/blog/2018/10/pymetamap">PyMetaMap</a></b><br /> Python interface for MetaMap, the biomedical named entity recognition and concept mapping system developed by the National Library of Medicine.<br /> [<a href="https://github.com/AnthonyMRios/pymetamap">code</a>]</li><br />

<li><b>advRelCNN</b><br /> Python implementation of an adversarial neural network for unsupervised domain adaptation in biomedical relation classification.<br /> [<a href="https://github.com/AnthonyMRios/adversarial-relation-classification">code</a>]</li><br />

<li><b>Multi-Label Zero-Shot Learning</b><br /> Neural methods for few-shot and zero-shot multi-label text classification when labels have a known structured relationship.<br /> [<a href="https://github.com/AnthonyMRios/multi-label-zero-shot">code</a>]</li><br />

<li><b>Med-Match CNN</b><br /> Matching-network-based convolutional neural network for few-shot assignment of medical diagnosis codes to electronic medical records.<br /> [<a href="https://github.com/AnthonyMRios/med-match-cnn">code</a>]</li><br />

<li><b>Bio-CNN</b><br /> CNN framework for biomedical text classification with support for auxiliary wide features and ordinal classification losses.<br /> [<a href="https://github.com/AnthonyMRios/bio-cnn">code</a>]</li><br />

<li><b>Relation Extraction RNN</b><br /> Bidirectional recurrent neural network implementation for biomedical relation extraction, including drug-drug interaction extraction.<br /> [<a href="https://github.com/AnthonyMRios/relation-extraction-rnn">code</a>]</li><br />

<li><b>SMM4H</b><br /> Supervised NLP framework for detecting adverse drug reaction mentions and classifying medication-intake messages in social media.<br /> [<a href="https://github.com/bionlproc/SMM4H">code</a>]</li><br />

<li><b>DeepRel</b><br /> Deep neural relation extraction framework combining convolutional and recurrent neural network approaches for chemical-protein relation extraction.<br /> [<a href="https://github.com/ncbi-nlp/DeepRel">code</a>]</li><br />

<li><b>Geographic Performance Disparities</b><br /> Data and analysis resources for measuring geographic disparities in the performance of offensive-language classification systems.<br /> [<a href="https://github.com/AnthonyMRios/Geographic-Performance-Disparities">code/data</a>]</li><br />

<li><b>SDOH-N2C2</b><br /> Neural information extraction system for identifying social determinants of health, their arguments, and relationships in clinical notes.<br /> [<a href="https://github.com/Zephyr1022/SDOH-N2C2-UTSA">code</a>]</li><br />

<li><b>RadiologySumm</b><br /> Multimodal framework for generating radiology report impressions from textual findings and chest X-ray information using retrieval and neural models.<br /> [<a href="https://github.com/Zephyr1022/RadiologySum-UTSA">code</a>]</li><br />

<li><b>CivilPromptReasoningGPT4</b><br /> GPT-4 prompting, chain-of-thought, retrieval, and prompt-ensembling framework for legal argument reasoning in civil procedures.<br /> [<a href="https://github.com/danschumac1/CivilPromptReasoningGPT4">code</a>]</li><br />

<li><b>LLM-Cipher</b><br /> Framework for detecting machine-generated text across different LLM generators and domains using representations from pretrained language models.<br /> [<a href="https://github.com/SecureAIAutonomyLab/LLM-Cipher">code</a>]</li><br />

<li><b>BikeFrames</b><br /> Code and data for detecting how cyclists are portrayed in news coverage, including the BikeFrame Chain-of-Code framework for analyzing perception, accidents, and fault.<br /> [<a href="https://github.com/Zephyr1022/BikeFrames">code/data</a>]</li><br />

<li><b>Text-to-SQL Schema Inference</b><br /> Framework for studying zero-knowledge schema inference attacks and information leakage in LLM-based text-to-SQL systems.<br /> [<a href="https://github.com/klisura-code/Text2SQL-Project">code</a>]</li><br />

<li><b>MA-ToT</b><br /> Multi-agent Tree-of-Thought reasoning framework that uses multiple reasoning agents together with a validator agent to identify and remove faulty reasoning paths.<br /> [<a href="https://github.com/SecureAIAutonomyLab/MA-ToT">code</a>]</li><br />

<li><b>Clinical LLM Knowledge Boundaries</b><br /> Probing framework for comparing the internal representations, knowledge boundaries, and robustness of clinical and general-purpose large language models.<br /> [<a href="https://github.com/Zephyr1022/knowledge-boundaries">code</a>]</li><br />

<li><b>Speculative Storytelling for Healthcare AI</b><br /> Human-centered framework that generates speculative user stories and supports multi-agent discussions to help people anticipate potential benefits and harms of healthcare AI systems.<br /> [<a href="https://github.com/Zephyr1022/speculative-storytelling-healthcare">code</a>]</li><br />

<li><b>Vision-to-Policy (V2P)</b><br /> Multimodal access-control framework that uses vision-language models to translate access-control diagrams into entities, relationships, and structured policy representations.<br /> [<a href="https://github.com/UTSA-ICS/Rethinking-Access-Control-Policy-Authoring-as-a-Multimodal-Challenge">code</a>]</li><br />

<li><b>LLM Access-Control Datasets</b><br /> Access-control benchmark generation framework and datasets built from Spider and BIRD for evaluating whether LLMs correctly permit or deny database queries under role-based policies.<br /> [<a href="https://github.com/klisura-code/LLM-Access-Control-Datasets">code/data</a>]</li><br />

<li><b>TRACER</b><br /> Framework for detecting task-oriented dialogue failures before a conversation ends using dialogue trajectories and language-model representations, with tools for failure recovery and evaluation.<br /> [<a href="https://github.com/erfan-nourbakhsh/TRACER">code</a>]</li><br />

<li><b>BiomedicalRAG</b><br /> Large-scale evaluation framework for biomedical retrieval-augmented generation across multiple medical QA datasets, retrieval corpora, retrieval methods, and open-source LLMs.<br /> [<a href="https://github.com/erfan-nourbakhsh/BioMedicalRAG">code</a>]</li><br />

<li><b>MedProb</b><br /> Framework for probing the internal representations of vision-language models for medical visual question answering, including hidden-state extraction, linear probing, prompting, and fine-tuning experiments.<br /> [<a href="https://github.com/erfan-nourbakhsh/MedProb">code</a>]</li><br />

<li><b>Prompting Underestimates</b><br /> Evaluation framework for comparing prompting and representation probing of large language and vision-language models on time-series classification tasks.<br /> [<a href="https://github.com/danschumac1/PromptingUnderestimates">code</a>]</li><br />

<li><b>DoppelBot</b><br /> Experimental platform, analysis tools, and anonymized data for studying how middle-school students distinguish human collaborators from LLM-controlled agents in live interactions.<br /> [<a href="https://github.com/danschumac1/MiddleSchoolersIdentify">code/data</a>]</li><br />
